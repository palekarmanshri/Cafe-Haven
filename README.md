☕Cafe Haven

Cafe Haven is a dynamic web-based cafe management application developed using Java, JSP, Servlets, JDBC, and MySQL. 
The application provides a seamless experience for users to browse the menu, register, log in, manage their cart, place orders, and generate invoices. 
It is designed with a clean and user-friendly interface to simplify online food ordering.
-------------------------------------------------------------------------------------------------------------------------------------------
**✨ Features**

- 👤 User Registration and Login
- 🍽️ Browse Cafe Menu
- 🛒 Add and Remove Items from Cart
- 💳 Secure Checkout Process
- 🧾 Automatic Invoice Generation
- 📦 Order Confirmation
- 📱 Responsive and User-Friendly Interface
- 🗄️ Database Connectivity using JDBC

**🚀 Getting Started**

### Clone the Repository

```bash
git clone https://github.com/palekarmanshri/Cafe-Haven.git
```

### Open the Project

- Open NetBeans IDE.
- Import the project.
- Configure Apache Tomcat Server.
- Create the MySQL database.
- Update the database credentials in the JDBC connection.
- Run the project.

-------------------------------------------------------------------------------------------------------------------------------------------

**🎯 Project Objective**

The objective of this project is to develop a user-friendly cafe management system that enables customers to browse the menu, place orders online, and complete the ordering process efficiently while demonstrating Java Web Development concepts using JSP, Servlets, JDBC, and MySQL.
